# MarkupFlow — каталог веб-компонентов

Учебный проект для курсовой «Использование встроенных редакторов разметки для ускорения разработки веб-интерфейсов».

## Назначение

Интерактивный каталог шести начальных компонентов с поиском, фильтром категорий и формой добавления. Новые записи сохраняются в localStorage. Интерфейс основан на семантическом HTML, адаптивном CSS и JavaScript без внешних библиотек.

## Как запустить

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Можно также использовать локальный HTTP-сервер редактора. Открытие HTML как `file://` может блокировать ES-модули в отдельных браузерах.

## Автоматические проверки

Нужен Node.js 20+ (для встроенного тест-раннера):

```bash
npm test
```

35 тестов охватывают нормализацию, валидацию, поиск, фильтрацию, добавление, восстановление данных и подсчёт категорий. Автоматические тесты проверяют чистые функции, **но не заменяют ручную проверку адаптивности и доступности в браузере**.

## Встроенные средства редактора

- HTML IntelliSense: подсказки тегов и атрибутов.
- Emmet: сокращения вида `ul>li*3` и `article.card>h3+p`.
- CSS IntelliSense: свойства и значения.
- Форматирование, парные теги, подсветка синтаксиса.
- `.vscode/settings.json` задаёт правила для VS Code.

## Ограничения

Это локальный учебный проект без сервера данных и авторизации. `localStorage` доступен только на данном устройстве и origin. Данные не синхронизируются между участниками. Отсутствие дефектов безопасности не утверждается. Время разработки не измерялось на группе пользователей; ускорение рассматривается как потенциальное снижение количества ручных операций, а не как доказанный процент экономии времени.
