# Учебная методика сравнения операций

Эксперимент носит качественный характер и не заменяет измерение производительности разработчиков.

| Операция | Ручной ввод | Встроенная поддержка редактора | Проверка |
|---|---|---|---|
| Карточка HTML | Писать открывающие и закрывающие теги | Emmet `article.card>h3+p` | DOM-структура |
| Три пункта списка | Вводить шесть тегов li | Emmet `ul>li*3` | Число элементов |
| CSS Grid | Вспоминать имена свойств | CSS IntelliSense | Адаптивное отображение |
| Разметка формы | Вручную сверять атрибуты | HTML IntelliSense | HTML-валидация |
| Структура документа | Вводить каркас HTML | Emmet `!` | Наличие head/body |

Количественный эффект не вычисляется без замера реального времени. Для воспроизводимой проверки интерфейса откройте страницу, проверьте шесть карточек, выполните поиск, смените категорию, добавьте запись, обновите страницу и убедитесь в сохранении. Отдельно оцените узкий экран и навигацию клавиатурой.
